A fence is mostly posts. Everything that fails on a fence, sagging gates, leaning
runs, panels that pull away at the corner, traces back to a post that was not set
deep enough, not set in enough concrete, or not set on the line.

We start from the line, set the posts to it, and hang gates on hardware sized for
the span rather than the one that came in the box.
