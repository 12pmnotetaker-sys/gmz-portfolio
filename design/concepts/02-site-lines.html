Why it holds

The part
you never see

Almost everything that goes wrong with a patio goes wrong below it.

A base that was not compacted in lifts, a subgrade that holds water, a wall built without drainage behind it. We build the base to what the soil and the load call for, and resolve water before the surface goes down.

A fence is mostly posts.

Sagging gates and leaning runs trace back to a post that was not set deep enough, not set in enough concrete, or not set on the line. We start from the line and hang gates on hardware sized for the span.

Soil comes first.

What is under the mulch decides how much of a planting plan is still alive in year three. Spacing is set by mature size rather than by how it looks on install day.
